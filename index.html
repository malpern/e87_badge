The hardware

A 1.7-inch screen
you pin to your jacket.

The E87 is a round 368 × 368 LCD badge — sold generically for anime and cosplay fans, normally locked to its own phone app. This library talks to it directly over Bluetooth. Below: two of ours, photographed running code from this repo.

Sold under many names as the “E87” badge — Amazon, AliExpress, and others. This project is an independent, reverse-engineered client; it isn’t affiliated with any seller.

hello_badge.py
import asyncio
from e87_badge import E87Client

async def main():
    async with E87Client("46:8B:00:01:83:9C") as badge:
        await badge.send_text("Hello", size=96)
        await badge.send_gif("pulse.gif")

asyncio.run(main())

An honest negative result

We found the switch.
The firmware won't run it.

Uploading is slow — 5–15 s for a still. The device's own SDK has a command to flip between assets you've already sent, with no re-upload. So we implemented it… then tested it on real hardware. On firmware V11.1.0.3 the badge rejects it.

reactive.py
async with E87Client(addr) as badge:
    # upload each asset once — returns its on-device path
    idle   = await badge.send_gif("idle.gif")
    active = await badge.send_gif("active.gif")

    async for present in presence():   # your sensor
        await badge.show_file(active if present else idle)
        # ↑ raises E87ProtocolError on V11.1.0.3 — wrap + re-upload
What the badge says

Acknowledged — then refused.

The badge accepts the command at the transport layer, then answers with RCSP status 0x02: the “watch dial” subsystem this needs isn't wired up in the display-badge firmware, so it always shows the most-recently-uploaded file. (Curiously, file-browse is accepted — the filesystem is enumerable; there's just no “show this one.”)

Why ship it anyway? The command is real, and other or newer firmware may honour it. e87 probe checks any unit by reading the status byte, and show_file() raises E87ProtocolError so your code falls back to a normal upload automatically. Read the full investigation →
No magic, just bytes

Every frame, documented.

The protocol was recovered from BLE captures and a decompiled APK, then re-implemented in clean Python — FE framing, the JieLi auth cipher, the windowed upload state machine, and the newly-found switch commands. It's all written down.
